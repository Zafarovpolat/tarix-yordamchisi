# Tarix Yordamchisi — план развития

> 3D голосовой ассистент по истории Узбекистана.
> Прод: <https://tarix-yordamchisi-ai.netlify.app>
> Документ фиксирует согласованный чек-лист следующего этапа и обновляется по мере выполнения.
> Обновлено: 2026-08-24

## Текущее состояние (от чего отталкиваемся)

- Одностраничный `index.html` (Three.js + Ready Player Me), без сборки.
- Serverless-функции Netlify без зависимостей: `answer`, `tts`, `stt`.
- Пайплайн запроса: **STT → answer → TTS**
  `answer`: сначала проверенная база фактов (`facts-db.json`), затем Wikipedia, затем Groq LLM.
- Замеры латентности (только серверная часть, у клиента сверху ещё пинг до сети):

  | Этап | Время | Комментарий |
  |------|-------|-------------|
  | STT (Whisper, uz) | ~2.0 с | распознавание речи |
  | answer (база фактов) | ~0.7 с | мгновенный путь |
  | answer (Wikipedia + Groq) | ~1.2 с | если факта нет в базе |
  | TTS (Edge, uz) | ~2.0 с | синтез речи |

  Итого от «замолчал» до «аватар заговорил» ≈ **5 с** (этапы идут последовательно) + холодные старты функций.
